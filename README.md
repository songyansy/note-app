# 读书笔记管理应用

基于 Next.js 15 + React 19 + Tailwind CSS + shadcn/ui + Zustand 构建的读书笔记管理应用。

## 功能
- 添加 / 删除笔记
- 按分类筛选
- 搜索过滤
- 全站暗色模式（跟随系统）
- 本地持久化存储

## 技术栈
- Next.js 16.4.2（App Router）
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- Zustand（+ persist 中间件）
